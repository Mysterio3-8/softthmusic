# YouTube → VK Auto Publisher

Программа автоматически переносит видео с одного или нескольких YouTube-каналов
в сообщество ВКонтакте: скачивает ролик, собирает пост (название + описание +
рекламный блок), ставит его в **отложенные записи** ВК, исключает повторы и
удаляет скачанные файлы. Рассчитана на личное использование, интерфейса нет —
работа через конфиг и консоль.

## Как работает

Запуск раз в сутки (cron / планировщик Windows). За один запуск:

1. Читает список каналов из конфига.
2. Находит первые `posts_per_day` (по умолчанию 3) неопубликованных ролика,
   идя по каналам по порядку: кончились на первом — берёт со второго и т.д.
3. Скачивает каждый в среднем качестве (`yt-dlp`).
4. Загружает видео в сообщество ВК.
5. Создаёт отложенные публикации на заданное время (напр. 09:00 / 15:00 / 21:00).
6. Записывает YouTube ID в SQLite (повторная публикация исключена).
7. Удаляет скачанные файлы и завершает работу.

## Установка

```bash
python -m venv venv
venv\Scripts\activate            # Windows
# source venv/bin/activate       # Linux
pip install -r requirements.txt
```

Нужен установленный **ffmpeg** (yt-dlp склеивает видео и аудио) — доступен в PATH.

## Настройка

```bash
cp config.example.yaml config.yaml
cp .env.example .env
```

- `.env` → `VK_TOKEN` — user/admin токен сообщества со scope `video, wall, groups`.
  Групповой токен **не подходит** для загрузки видео (VK error `[27]`).
  Быстро получить: https://vkhost.github.io/
- `config.yaml` → `vk.group_id`, список `youtube.channels`, время публикаций,
  рекламный текст `ad_block` (меняется без правки кода).

## Запуск

```bash
python app/main.py            # один прогон (для cron)
python app/main.py --schedule # постоянный процесс: ежедневно в 00:00 + ретраи
```

### Cron (Linux)

```
0 0 * * * cd /opt/softthmusic && venv/bin/python app/main.py >> logs/cron.log 2>&1
```

### Планировщик задач (Windows)

Создать ежедневную задачу, действие:
`C:\...\softthmusic\venv\Scripts\python.exe C:\...\softthmusic\app\main.py`,
рабочая папка — корень проекта.

## Обработка ошибок

При ошибке загрузки в ВК ролик помечается `error` с временем ретрая
(по умолчанию +60 и +180 минут). В режиме `--schedule` ретраи выполняются
внутри процесса; в режиме одного запуска ролик берётся заново на следующем
суточном прогоне.

## База данных

SQLite (`data/publisher.db`). На ролик хранится: YouTube ID, канал-источник,
название, дата обработки, статус (`published` / `error`), счётчик ошибок.

## Структура

```
app/
├── config.py            # загрузка config.yaml + .env
├── database.py          # SQLite: дедуп, статусы, ретраи
├── youtube.py           # yt-dlp: список роликов канала, скачивание
├── vk_client.py         # загрузка видео + отложенная запись в ВК
├── post_builder.py      # сборка текста поста
├── schedule_planner.py  # расчёт времён публикации
├── publisher.py         # оркестрация одного прогона
├── logger.py            # логирование
└── main.py              # точка входа (--once / --schedule)
```

Тесты: `pytest tests/ -v`
